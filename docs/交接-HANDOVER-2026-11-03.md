## 5. 本次会话踩过并已写进记忆的坑（摘要）

1. **`npx next build` 是唯一正解**：直调 CLI 实体 worker 崩（4294967295 / trace EPERM）。铁律 17 已修正为限定「非 next 工具」；但 `next start` 反之要 `node .../next start`。
2. **删 `.next` 必须补 `npx next typegen`**：否则 Next 生成类型丢失，TS6053。
3. **沙箱拦截 + 杀软瞬态窗口**是 EPERM 真因之一：非沙箱通道一次通过。
4. **grep 交替必须加引号**：`grep "speed|velocity"`，不加引号是管道——曾把 21 命中误判为 0。
5. **check-commit-scope 误报**：`git add -A` 卷入 docs/ 触发敏感内容命中，commit 前须 `git restore --staged docs/`。
6. **StrictMode 双挂载**曾让开屏永久遮挡：已通过移除 `sessionPlayed` 标记 + 挂 layout 根结构性解决（客户端路由不播是结构性行为，无已播标记）。
7. **需求 3 误判教训**：前端曾断言「巴士段从未有 catchHint」，实际是 S4 删了 `tierText` 回退——恢复回退即可，不是造新逻辑。负责人原话纠正过一次，详见日志。
