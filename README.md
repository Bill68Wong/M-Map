# M Map

澳门公共交通导航 —— 巴士与轻轨的**门到门**方案。

输入起点终点，得到一条能照着走的路线：步行到站、上哪条线、在哪换乘、还有几分钟到站。
不是把一堆线路丢给你，而是算清「现在出门，几点能到」。

线上：<https://macaomap.vercel.app>

---

## 为什么做这个

澳门的公交查询有个具体的难处：**同一个目的地，往往有好几种走法**，而哪种更快取决于此刻车在哪。
官方 App 告诉你「下一班 5 分钟」，但不会告诉你「走到另一个站坐另一条线，反而早到 6 分钟」。

M Map 做的事：把 92 条巴士线、3 条轻轨线的实时到站信息，和步行时间一起算，
按**总耗时**排序给出方案。通勤是每天都要重复的事，省下的 10 分钟不是一次性的。

---

## 能做什么

### 路线规划

- 起点终点可以选站点、地图点、收藏地点
- 方案里每一步都有依据：走几分钟、坐几站、换乘要不要跑
- 「赶得上 / 赶不上」直接说清楚，不给模糊的「建议提早出发」

### 实时导航

- 上车后自动识别你在哪辆车上（不用手动选车牌）
- 沿途报站，快到了会提示
- 切到后台、网络抖一下，回来还是准的

### 收藏与常用

- 常走的起终点存成一组，打开就是一键查询
- 单条路线也能单独收藏

### 其他

- 线路全景页：一条线的所有站点与走向，看得见整条线
- 步行导航：最后一段怎么走，箭头提示
- 到站提醒：下车前提醒，不用一直盯屏幕

## 数据从哪来

实时到站数据取自**澳门交通事务局（DSAT）公开报站接口**。

本项目：

- **非商业**用途，个人维护
- 注明数据来源与取得日期
- 不修改原始数据内容
- 派生值（统计、推算时长等）在站内说明算法

完整说明见站内 `/help` 页的「数据来源与合规」区块。

> 预测到站时间是基于历史数据的推算，不是官方承诺。实际以车辆运行为准。

## 技术

| 层 | 用的什么 |
|---|---|
| 前端 | Next.js 15（App Router）· React 19 · TypeScript（strict） |
| 后端 | Next.js Route Handlers（Vercel Serverless，香港区域） |
| 数据库 | Supabase（PostgreSQL） |
| 地图 | 高德 JS API 2.0（密钥经服务端代理注入，不下发浏览器） |
| 数据源 | 澳门交通事务局（DSAT）公开报站接口 |

规模：92 条巴士线路 · 3 条轻轨线路，覆盖全澳。

## 本地运行

```bash
git clone https://github.com/Bill68Wong/m-map.git
cd m-map
npm ci
cp .env.example .env     # 填入 DATABASE_URL 与地图密钥
npm run dev              # → http://localhost:3000
```

常用命令：

```bash
npm run dev            # 本地开发
npm run build          # 生产构建
npm run lint           # 代码风格检查
npx tsc --noEmit       # 类型检查
```
